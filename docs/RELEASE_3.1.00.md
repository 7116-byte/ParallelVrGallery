# 3.1.00 / 30100 验收

本次普通版从 3.0.08 / 30008 迭代，沿用完整 Git 历史、原包名和原 debug 签名。旧的未提交修改与未跟踪资料在修改前已完整保存在本机私密快照中；原忽略规则和 Wrapper 已保留。没有升级应用依赖或清理旧备份，Pro 未参与构建或发布。

## 变化

- 全部、相册、生成管理、Viewer、设置、诊断、任务、引导与确认弹窗统一主题。列表、选项和设置适配系统深浅色、不同窗口及大字体。
- 浮动导航与 Viewer 操作槽按实际高度避让；普通提示短暂显示，详情仍可从任务面板回看。Viewer 控件隐藏时间尊重系统辅助功能建议。
- 图片双眼直接绘制同一位图的源区域，减少主线程复制；保留共同缩放/偏移和原手势数学规则。视频仍为单播放器、SurfaceTexture 与 OpenGL 双眼视口。
- 视频按 settledPage 和 Activity 前后台状态分配播放，保留用户明确暂停；加载、失败和重试可见。
- 独立 navigation_v1 保存来源、相册、生成版本、列数和位置。冷启动恢复来源页，不自动恢复 Viewer/VR 或启动图片生成。
- 权限解释先于系统请求，支持选定媒体访问；增加可重复打开的使用指南。缓存删除、替换与重生提供范围确认。
- 更新下载增加原证书校验并校正单次下载进度；修复音轨 extractor/codec 标志混用。

- 手机：3072×2304 真实复杂图的已有缓存，SBS 6144×2304；平板：2309×3078 复杂图的已有缓存，SBS 4618×3078。均通过双指约 2× 放大、单指改变共同偏移、双击复位和左右眼非黑画面检查。没有对真实图片启动新生成。
- 手机专用相册仅含获准的三张合成图及一个无私人内容短视频。三图生成完成；视频 94 帧完成，后台处理和已有帧缓存复用有原始日志。未删除私人媒体、既有缓存或测试样本。
- 最终 APK 的视频只读测试通过：明确暂停后回桌面/返回仍为暂停；旋转并进行六轮图片/视频切页手势后，完成状态和左右眼非黑画面均通过检查。该短样本不能覆盖所有编码与系统播放器实现。
- 从专用图片进入诊断页后强制结束进程，重新启动恢复专用相册及四项网格，未恢复 Viewer/VR。诊断页、冷启动截图和原设置文件哈希均有本机记录。
- 持续按住跨 Pager 临界位置后返回并松手，合成图和复杂图测试通过。保存了现场 gfxinfo 与内存报告；复杂图一次整段流程有 4.20% deadline jank，包含启动、导航和解码，不能当作纯拖动基准或无顿挫证明。
- 已检查全部、相册、生成、任务、设置和指南；系统深浅色、平板横屏及手机约 320 dp 宽 / 1.8× 字体有私密截图。大字体选项自然换行、设置可滚动，导航槽为内容留出空间。

私人图片名称、设备序列号、原始截图和日志不提交。自动化命令必须读取 `result=PASS/FAIL`；脚本退出 0、测试包安装成功、编译成功均不等于真机通过。

## 继续跟踪

- 持续按住跨 currentPage 边缘的主观顿挫、快速视频切换偶发黑屏仍需更广泛真机与用户复核。本次有限样本通过，不宣布全部设备修复。
- 生成页恢复 ALL/ALBUM 来源暂停任务的需求与 jobAllowedInCurrentContext 的 GENERATED 判断可能不一致，队列规则本次未改。
- 现有 Compose/TFLite 原生库仍有 16 KB ELF 对齐限制；当前设备的系统兼容提示未隐藏。4 KB 设备验收不能证明 16 KB 兼容。
- 强制 GPU 选项与无 CPU fallback 规则保留；本次新生成样本使用既有 CPU 配置，不等于全部 GPU 模式已验收。Qualcomm 权重和 Video Depth Anything 移动端资产仍缺失。
- 单张原生推理被杀后不会无损续跑；视频历史任务按原规则恢复为暂停，需要用户明确继续。
