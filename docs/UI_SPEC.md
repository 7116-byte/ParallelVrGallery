# 3.1.00 界面规范

目标是简洁的本地创作工具：内容优先，操作可触及，状态可追溯。普通版与 Pro 保持独立。

- 系统深浅色直接驱动 Compose 主题与系统栏图标。紫色为主要操作，柔和绿色辅助表达；媒体/双眼 Viewer 始终使用深色画布。
- 8/12/16/20/24 dp 间距，按钮至少 48 dp 触摸范围。卡片圆角 20–28 dp。正文沿系统字号缩放，不以缩小到 7–9 sp 适配密集布局。
- 图库顶栏只保留来源标题、任务、刷新、设置；高度实测后用于首行避让。滚动时顶栏使用半透明表面。底部圆角悬浮导航槽实测高度后为内容留出末行空间，不叠加固定大空白。
- 全部/相册/生成沿用既有来源和顺序；网格密度只调整显示，不改变持久化队列或预加载范围。图片与相册/版本卡片根据窗口宽度和系统字号分别限制列数。
- 设置采用宽度受限的可滚动分组卡片，选项自然换行；手机、平板、小窗、横屏及大字体使用相同组件。没有重复的保存区，参数仍按原规则即时保存。
- Viewer 的媒体画布、左右翻页、缩放拖动和双眼同步规则保留。工具条与播放槽使用同一深色 Material 主题，尊重安全边距；播放仅在 Activity 处于前台且当前页激活时继续。
- 任务面板只读，不自动启动/恢复任务。图片/视频状态独立，错误原因可见。消息由固定 Snackbar 展示，并可进入状态面板回看；空内容、授权、模型等待及失败有明确入口。
- 首次进入在请求权限前解释用途。支持 Android 14 的选定媒体访问，拒绝后可转系统设置。新手指南同时从设置再次打开，说明图片自动 VR、视频独立队列、模型和强制 GPU 的影响。
- 破坏性操作需要清楚展示范围并确认；确认框本身不执行操作。测试设备只对明确获准的合成样本生成内容，私人媒体/缓存不作删除测试。

代表界面先完成主题、图库和设置，再沿同一规范覆盖生成管理、任务、Viewer、诊断、权限与弹窗。真机矩阵与未定案问题记录在版本验收中。
